# EDA-on-NYC-Taxi-Records
This exercise aims to give you an idea of applying EDA in real-world scenarios. In addition to using the techniques that you have learnt in the EDA module, you will develop a basic understanding of analytics for real-world situations, how to integrate them into a narrative and draw usable insights. You will learn about exploratory data analytics with the help of a data set on yellowtaxi rides in New York City.
